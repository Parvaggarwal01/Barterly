# Code of Conduct

## Our Pledge

We are committed to making Barterly a welcoming, respectful, and beginner-friendly open-source project for everyone.

Contributors, maintainers, mentors, and community members are expected to participate with empathy, patience, and professionalism.

## Expected Behavior

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language.
- Respecting different experience levels and backgrounds.
- Giving constructive feedback that focuses on the work, not the person.
- Asking clear questions when something is confusing.
- Accepting feedback gracefully.
- Keeping discussions relevant to the project.
- Helping new contributors understand the codebase and contribution process.

## Unacceptable Behavior

Examples of unacceptable behavior include:

- Harassment, intimidation, insults, or personal attacks.
- Sexist, racist, casteist, homophobic, transphobic, ableist, or otherwise discriminatory language.
- Trolling, spam, or repeated off-topic comments.
- Publishing someone else's private information without permission.
- Plagiarism or submitting work copied from others without credit.
- Repeatedly demanding reviews, assignments, or merges after maintainers have responded.
- Any conduct that maintainers reasonably consider inappropriate for a professional open-source community.

## Contributor Responsibilities

Contributors are expected to:

- Read `README.md` and `CONTRIBUTING.md` before opening a pull request.
- Work only on issues assigned to them unless a maintainer says otherwise.
- Keep pull requests focused and respectful of reviewer time.
- Test their changes and explain what was tested.
- Credit sources, tools, or references when relevant.

## Maintainer Responsibilities

Maintainers are expected to:

- Apply this Code of Conduct fairly and consistently.
- Clarify issue scope and review expectations.
- Give constructive review feedback.
- Label, close, or lock discussions when needed to protect the community.
- Remove comments, issues, pull requests, or contributors that violate this Code of Conduct.

## Reporting

If you experience or witness unacceptable behavior, report it to a project maintainer.

When reporting, include:

- A short description of what happened.
- Links to the issue, pull request, discussion, or comment.
- Screenshots if the content may be edited or deleted.
- Any context that helps maintainers understand the situation.

Maintainers will review reports as soon as reasonably possible and take action based on the severity and context of the incident.

## Enforcement

Maintainers may take any of the following actions:

1. Private clarification or warning.
2. Public reminder to follow the Code of Conduct.
3. Temporary restriction from issues, pull requests, or discussions.
4. Removal from assigned issues.
5. Blocking or banning from the project.

Severe violations may result in immediate removal from the project community.

## Scope

This Code of Conduct applies to all Barterly project spaces, including GitHub issues, pull requests, discussions, project boards, documentation, and community channels connected to the project.
